Little Picture World v41 — 80%-style visual preview, not a full premium-art library.

This update includes 9 3D-like assets for Apple, Cat, Dog, Duck, Lion, Tiger, Elephant, Bicycle, Teddy Bear. The first six were already part of the V15 embedded 3D asset bank; Elephant, Bicycle and Teddy Bear were reframed from existing illustrated mockup screenshots. They are NOT newly generated standalone 3D objects, and their scene/background can differ. Other 13 objects retain older illustrations to keep quiz content playable.

The anti-repeat deck now contains 22 names, and deals 10 distinct words per session; all objects must be seen before the cycle is reset. For truly consistent visuals, 13 more standalone assets are still required and the target 200-object library is not complete.

Only Little Picture World files/UI have changed deliberately. Picture Spelling, Coloring Book, Learn to Draw and all other modules remain as in v40. Never overwrite V14. Back up browser data before deploying any new build.
